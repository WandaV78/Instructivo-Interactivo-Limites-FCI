Este instructivo interactivo permitirá subir los Reglamentos de Gestión de cada Fondo Común de Inversión 
y el mismo extraerá la información para convertirla en dato configurable de los limites de cada Fondo y controlar su cartera.

This interactive guide will allow you to upload the Management Regulations of each Common Investment Fund 
and it will extract the information to convert it into configurable data of the limits of each Fund and control its portfolio.
